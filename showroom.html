ต่อเข้ากับ extension
  • โค้ดเรนเดอร์ในหน้านี้ (canvas + MediaRecorder) ย้ายไปรันใน offscreen document ของ extension ได้ตรงๆ ไม่ต้องใช้ server
  • extension ส่งรูปของรถแต่ละคันพร้อมข้อมูลรุ่น ปี ราคา เข้ามา แล้วได้ไฟล์วิดีโอกลับไป จากนั้นส่งต่อให้ขั้นตอนโพสต์ TikTok
  • สุ่มสไตล์ให้แต่ละคันได้ คลิปในหน้าโปรไฟล์จะได้ไม่ซ้ำกันหมด
  • คลิปไม่มีเสียง ให้เลือกเพลงจากคลัง TikTok ตอนโพสต์ จะไม่ติดลิขสิทธิ์ ถ้าใช้ Beat Sync ให้ตั้ง BPM ให้ตรงกับเพลงที่จะใช้
